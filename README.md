# Franchise Finmodel — прототип

Демонстрационный прототип финансового калькулятора франшизы «ПожзнакЪ». Проект хранится в GitHub; публичное развёртывание пока не подключено.

## Запуск
Проект — статический сайт без сборки и сервера. Для локального просмотра достаточно открыть `index.html` в браузере. Cloudflare Pages и другие варианты публикации пока намеренно не подключаются.

## Что уже есть
- адаптивный интерфейс для desktop и mobile;
- пошаговое заполнение параметров;
- выбор актуального пакета франшизы: «Специалист» или «Эксперт»;
- ввод паушального взноса (базовое значение — от 850 000 ₽) и фиксированного роялти (25 000 ₽/мес.) с возможностью корректировки;
- ввод исходных параметров инвестиций, продаж и расходов;
- редактируемые строки с количеством и ценой для мебели, офисного оборудования и рабочего инструмента;
- возможность добавлять прочие стартовые и ежемесячные расходы;
- редактируемая структура услуг и долей выручки;
- кредитование полностью исключено из расчётов;
- расчётное ядро вынесено в `calculator.js`;
- автоматический предварительный прогноз на 24 месяца;
- график выручки, расходов и прибыли;
- сохранение черновика в localStorage браузера;
- проверка контрольного сценария: инвестиции для расчёта окупаемости 1 227 000 ₽, выручка за 24 месяца 31 833 714 ₽, чистая прибыль 13 958 141 ₽ и окупаемость 7 месяцев (исходные значения Excel, УСН 6%);
- сброс расчёта.

## Важно: статус расчётного ядра
Расчётное ядро в `calculator.js` и интерфейс в `index.html` — **прототип, а не утверждённая финансовая модель заказчика**. Подтверждённые формулы продаж, сезонности, стартовых инвестиций и части ежемесячных расходов перенесены из Excel. Налог 15% пока считается упрощённо; страховые отчисления воспроизводятся по значениям исходной книги и требуют подтверждения. Часть формул пока упрощена для демонстрации взаимодействия. До передачи клиентам необходимо:
1. перенести все неудаляемые параметры из исходного Excel;
2. подтвердить точный паушальный взнос для выбранного пакета и проверить фиксированное роялти по актуальному договору; подтвердить логику сезонности, роста продаж, ФОТ, страховых взносов и налогов;
3. удалить выделенные заказчиком жёлтые строки и все зависимости от них;
4. восстановить повреждённые ссылки `#REF!` в исходной книге либо заменить подтверждённой формулой;
5. сверить контрольные сценарии сайта с Excel.

Не использовать текущие результаты для принятия инвестиционных решений.

## Технические решения MVP
- HTML/CSS/JavaScript без фреймворка;
- Chart.js для графика;
- localStorage для временного хранения на устройстве;
- без регистрации, базы данных и серверного API.
